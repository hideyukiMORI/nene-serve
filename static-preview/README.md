# NeNe Serve — static page previews

Standalone, dependency-free HTML snapshots of every admin-console screen, styled
with the application's real compiled stylesheet (`assets/app.css`) and filled
with sample data. No server, backend, or build is required.

Open `index.html` (or any page) directly in a browser — e.g. double-click, or
`file://.../static-preview/index.html`.

Pages: login, set-password, placements, creatives, review, metrics, marketplace,
users, settings.

These are **visual previews only** — buttons/links are inert; there is no live
data, auth, or API. For the running app see the project README and
`docs/tutorial/first-campaign.md`.
