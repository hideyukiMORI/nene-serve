# Scope Boundary

```
Publisher site
    │ serve.js
    ▼
NeNe Serve — placements, creatives, imp/click (SSOT)
    │ optional HTTP
    ├── NeNe Invoice (advertiser charges / payments)
    ├── NeNe Deal (campaign as opportunity — optional)
    └── NeNe Records (creative asset metadata — read optional)

NeNe Contact / Concierge — separate embeds, separate SSOT
```

Serve does not consume or produce contact **submissions** or chat **sessions**.
