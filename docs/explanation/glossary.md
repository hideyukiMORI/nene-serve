# Glossary

Meanings in plain language. Identifier spellings: [`terminology.md`](./terminology.md).

| Term | Meaning |
| --- | --- |
| **Placement** | A named ad slot on a site (sidebar, footer, interstitial) |
| **Creative** | The asset shown (image, video, HTML5 bundle) |
| **Delivery plan** | Rules that pick which creative to show |
| **Weight** | Relative share among eligible creatives |
| **Cap** | Maximum impressions before a creative or campaign stops |
| **Fallback** | Default creative when nothing else is eligible |
| **Impression** | One counted ad view per measurement spec |
| **Click** | One counted click via redirect endpoint |
