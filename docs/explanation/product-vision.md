# Product Vision

**NeNe Serve** — self-hosted ad serving for publishers and niche ad networks on NENE2.

## Origin

Publishers rely on opaque SaaS ad tags or build fragile custom rotation. Operators want **control**, **metrics they can export**, and **optional self-serve advertisers** without surrendering data to a global exchange.

## North Star

- Register creatives and placements
- One-line `serve.js` on any site
- Weighted delivery with caps and fallback
- Charts + CSV + MCP for delivery planning
- Six-locale operator and embed experience
- Money flows through **Invoice** when marketplace mode is enabled

## Non-goals

- Contact forms, chat scenarios, invoice issuance, bank tooling, enterprise DSP

## MVP success

- Image creative + one placement + serve.js + imp/click + daily chart + CSV
- Six locale files with CI key parity
- OpenAPI + MCP read metrics
