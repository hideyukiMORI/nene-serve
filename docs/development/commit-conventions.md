# Commit Conventions

English Conventional Commits (ADR 0008). Include `(#issue)` in subject.

```
feat(placement): add public serve endpoint (#12)
```

Types: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`, `build`, `ci`.

Locale-only PRs: `feat(i18n): add embed consent strings for ko and de (#n)`.
