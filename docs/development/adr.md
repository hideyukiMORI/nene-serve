# ADR Policy

Use `docs/adr/0000-template.md`. Required for scope, measurement, locale set, creative policy, and Invoice handoff changes.

**Billing / accounting / tax deviations** additionally require **tax/accounting professional sign-off (税理士 / 会計士)** recorded in the ADR — see `docs/explanation/billing-and-accounting-compliance.md` §0.

**Privacy / data-protection / consent deviations** require **privacy/legal sign-off** recorded in the ADR — see `docs/explanation/privacy-and-ad-compliance.md` §0.

**API security deviations** (auth model, CORS, tokens, redirects, rate limits) require **security sign-off** recorded in the ADR — see `docs/explanation/api-security-spec.md` §0.

**Creative safety deviations** (review workflow, acceptance, sandbox/CSP, scanning, enabling third-party tags) require **security sign-off** recorded in the ADR — see `docs/explanation/creative-review-and-safety.md` §0.
