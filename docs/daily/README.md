# docs/daily — Daily Reports

Day-by-day work log for the NeNe Serve repository. Format and rules follow the
fleet-wide source of truth `_work/daily-report-convention.md` (approved 2026-07-17).

## Role and boundary

- **`docs/daily/` (here)** … work done inside this repo (PRs/Issues touched, verified facts, remaining tasks).
- **`_work/daily/` / `_work/discussion-log/`** … cross-repo, strategy, and business discussions. Never recorded here (per the workspace-level convention).

One file per day, `YYYY-MM-DD.md`. No frontmatter. Numbers must state whether
they are measured or relayed. Multiple sessions on the same day append
`## Session 2` headings to the same file.

> Language note: the fleet convention defaults to Japanese; this repo has a live
> English-docs binding (ADR 0008). Until the fleet-level exception ruling
> (convention §7-1) lands, reports here follow the deal/vault interim precedent:
> fleet format, English body.
